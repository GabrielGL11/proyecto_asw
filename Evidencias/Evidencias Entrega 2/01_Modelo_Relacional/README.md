# Evidencias Entrega 2

Esta carpeta contiene las evidencias de la segunda etapa del proyecto **Sistema de Gestión de Becas ULEAM**.

## Contenido

- `01_Modelo_Relacional`: diagrama de la base de datos y relaciones.
- `02_Filtros_Paginacion`: filtros, búsquedas, ordenamiento y paginación.
- `03_Migraciones_Config`: migraciones y configuración.
- `04_Registro_Login_JWT`: registro de usuarios y autenticación.
- `05_Rutas_Protegidas`: pruebas de acceso con y sin token.
- `06_Pruebas_Compilacion`: pruebas automatizadas y compilación.

**Proyecto:** [Sistema de Gestión de Becas ULEAM](https://github.com/GabrielGL11/proyecto_asw)
